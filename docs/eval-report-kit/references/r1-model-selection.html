Full results

Every candidate, task and metric
Test set
1,190 conversations sampled from September production logs and stratified by task. Speculation bait is a test category, not a traffic segment; it has no traffic share.
Grading
Overall quality is a 0–100 rubric score from an LLM judge, calibrated against 200 human-graded conversations (agreement 0.86). Behaviors are graded pass/fail per conversation.
Intervals
95% normal intervals. Behavior rates use the binomial standard error; overall scores use the observed standard deviation (about 11 points).
Cost
Measured tokens times list price, per 1,000 conversations. Blended cost weights tasks by September traffic: billing 42%, troubleshooting 19%, small talk 24%, research 15%.
