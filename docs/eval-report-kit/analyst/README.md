# The analyst skill

The analyst skill lives in the evals package as data, at [`packages/evals/src/threetears/evals/analysis/analyst/skill/`](../../../packages/evals/src/threetears/evals/analysis/analyst/skill/). It ships in the wheel, and the report writer loads it from there (`threetears.evals.analysis.analyst.skill`). Edit it there; this directory holds no copy.

| File | What it is |
|---|---|
| `SKILL.md` | The analyst's role, workflow, report document and tools |
| `principles.md`, `stories.md`, `charts.md`, `statistics.md`, `writing.md` | The modules `SKILL.md` names |
| `exemplars/INDEX.md`, `exemplars/*.md` | The reasoning notes, and the index that names each one's structure |
| `editor.md` | The report editor's system text: the rubric and the review it returns |
| `README.md` | Notes for the skill's maintainers; no system text holds it |
