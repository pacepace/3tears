# underscore-access exemptions file.
#
# every entry is an exact (file, line, symbol) triple. each entry
# requires a preceding '# rationale: <specific reason>' line. "internal
# access needed" is not a rationale.
#
# format:
#   # rationale: why this access has no public alternative
#   path/relative/to/repo-root.py:42:_private_symbol
#
# maintained in lockstep with ruff's per-file-ignores for SLF001, wherever
# ruff reads them from -- the root pyproject.toml, and any nested ruff.toml,
# which is a FULL override the root file cannot reach past. every exemption
# here must have a matching ruff ignore so the two systems agree. no count of
# what this file CURRENTLY holds, anywhere in this header: it promised "the five
# sidecar ones" when the file had none, and again when it had eighty-nine.
# Figures describing a past state are fine -- they report what was, and cannot
# go stale.
#
# NOTE ON LINE NUMBERS: these triples ARE checked now, in both directions,
# by tests/enforcement/test_underscore_exemptions_resolve.py -- every entry
# must resolve to the symbol it names, and every private access on a
# per-file-exempted path must have an entry. That closes the drift this note
# was originally written to warn about: entries under such a path used to be
# documentation nothing read back, since the underscore walker scans
# packages/*/src only and never enters a tests/ tree.
#
# They still drift when a file is edited above them; the difference is that
# the drift now fails a test instead of sitting unnoticed. Regenerate rather
# than hand-edit -- one command, which carries every rationale forward by
# (path, symbol) so only a genuinely new access needs new text:
#   uv run python scripts/regen-underscore-exemptions.py
# It reads EVERY ruff config, not just the root pyproject.toml. Reading only
# the root is how five reviewed sidecar entries were deleted without anything
# noticing: packages/scrape/sidecar/ruff.toml is a full override the root
# cannot reach past.
#
# One trap in that procedure, learned the hard way: an inline `# noqa: SLF001`
# in a file that ALSO has a per-file ignore is redundant to ruff and invisible
# to this regeneration -- ruff honours the pragma and reports nothing, so the
# access silently never reaches this file. Six entries went missing that way.
#
# tests/enforcement/test_no_redundant_slf001_pragmas.py now enforces this: a
# path with a per-file SLF001 ignore may not also carry an inline pragma. It is
# the one direction a consistency check cannot cover, since a blinded access is
# never flagged in the first place.
